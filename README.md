# MAX-PUMP Discord Bot

Discord-бот для управления игровыми сессиями и взаимодействия с сообществом MAX-PUMP.

## Описание

Бот предоставляет следующие функции:

### Игровые команды (`/game`)
- **create** — Создать новую игру
- **rating** — Просмотреть рейтинг игроков
- **notify** — Уведомить пользователей о статусе заявки
- **join** — Присоединиться к игре
- **accept** — Одобрить игроков (с указанием количества)
- **user_setcharacter** — Изменить основного персонажа пользователя
- **user_addcharacter** — Добавить персонажа пользователю
- **user_removecharacter** — Удалить персонажа у пользователя
- **user_setstatus** — Изменить статус пользователя
- **user_remove** — Удалить пользователя из игры

### Профиль (`/profile`)
- Просмотр игрового профиля пользователя
- Статистика сыгранных игр
- История приглашённых пользователей
- Управление лайками

### Тикеты (`/ticket`)
- **create** — Создать новый тикет поддержки
- **close** — Закрыть тикет
- **adduser** — Добавить пользователя в тикет

### SteamID (`/steamid`)
- **my** — Показать свой SteamID
- **get** — Получить SteamID пользователя
- **set** — Установить свой SteamID
- **find** — Найти пользователя по SteamID
- **convert** — Конвертировать форматы SteamID

### Информация (`/info`)
- Получить информацию о серверах Garry's Mod

### Модерация (`/moderation`)
- **ban** — Забанить пользователя
- **unban** — Разбанить пользователя
- **banlist** — Список забаненных
- **addaccess** — Добавить доступ
- **removeaccess** — Удалить доступ

## Инструкция по установке на VDS с Windows 10

### Шаг 1: Установка необходимых инструментов

1. **Установка Node.js:**
   - Скачайте последнюю LTS версию с [nodejs.org](https://nodejs.org/)
   - Запустите установщик и следуйте инструкциям
   - Проверьте установку: `node --version` и `npm --version`

2. **Установка Git:**
   - Скачайте с [git-scm.com](https://git-scm.com/)
   - Установите с настройками по умолчанию
   - Проверьте: `git --version`

### Шаг 2: Клонирование репозитория

```bash
cd C:\Users\Administrator\Desktop
git clone <URL_репозитория> max-pump-bot
cd max-pump-bot
```

### Шаг 3: Создание виртуального окружения и установка зависимостей

```bash
# Установка зависимостей
npm install
```

### Шаг 4: Настройка конфигурации

Создайте файл `.env` в корне проекта:

```env
TOKEN=ваш_токен_бота_здесь
GAME_APPLY_PRIVATE_ID=1234567890123456789
GAME_CONTROL_CATEGORY_PRIVATE_ID=1234567890123456789
GAME_CONTROL_CATEGORY_OFFICIAL_ID=1234567890123456789
```

### Шаг 5: Запуск бота

```bash
# Обычный запуск
npm start

# Режим разработки (с автоперезагрузкой)
npm run dev
```

### Шаг 6: Настройка автозапуска через Планировщик задач

1. Откройте **Планировщик задач** (Task Scheduler)
2. Нажмите **Создать задачу**
3. Вкладка **Общие**:
   - Имя: `MAX-PUMP Discord Bot`
   - Выберите "Выполнять для всех пользователей"
4. Вкладка **Триггеры**:
   - Нажмите **Создать**
   - Начало задачи: "При запуске системы"
5. Вкладка **Действия**:
   - Нажмите **Создать**
   - Действие: "Запустить программу"
   - Программа: `cmd.exe`
   - Аргументы: `/c "cd /d C:\Users\Administrator\Desktop\max-pump-bot && npm start"`
   - Начать в: `C:\Users\Administrator\Desktop\max-pump-bot`
6. Нажмите **OK**

## Инструкция по добавлению бота на Discord-сервер

### Шаг 1: Создание приложения в Discord Developer Portal

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Войдите в свой аккаунт Discord
3. Нажмите **New Application**
4. Введите имя: `MAX-PUMP Bot`
5. Нажмите **Create**

### Шаг 2: Получение токена бота

1. В левом меню выберите **Bot**
2. Нажмите **Reset Token** под разделом "TOKEN"
3. Скопируйте токен и сохраните его в файле `.env`

### Шаг 3: Настройка разрешений (Privileged Gateway Intents)

В разделе **Bot** включите следующие опции:
- ✅ **SERVER MEMBERS INTENT**
- ✅ **MESSAGE CONTENT INTENT**

### Шаг 4: Генерация OAuth2 URL

1. В левом меню выберите **OAuth2 → URL Generator**
2. В разделе **SCOPES** выберите:
   - ✅ `bot`
   - ✅ `applications.commands`
3. В разделе **BOT PERMISSIONS** выберите:
   - ✅ **Manage Channels**
   - ✅ **Manage Roles**
   - ✅ **Send Messages**
   - ✅ **Embed Links**
   - ✅ **Attach Files**
   - ✅ **Read Message History**
   - ✅ **Manage Messages**
   - ✅ **Use Slash Commands**
   - ✅ **Use External Emojis**
4. Скопируйте сгенерированную ссылку

### Шаг 5: Добавление бота на сервер

1. Вставьте скопированную ссылку в браузер
2. Выберите сервер, на который хотите добавить бота
3. Нажмите **Authorize**
4. Подтвердите действие

## Руководство по использованию

### Основные команды

| Команда | Описание |
|---------|----------|
| `/game create` | Создать новую игру |
| `/game rating` | Посмотреть рейтинг |
| `/game join` | Присоединиться к игре |
| `/profile` | Посмотреть профиль |
| `/profile @user` | Посмотреть профиль другого пользователя |
| `/ticket create` | Создать тикет поддержки |
| `/steamid set <ID>` | Установить свой SteamID |
| `/info <1-4>` | Информация о сервере |
| `/ping` | Проверка работы бота |

### Навигация

Используйте кнопку **"Навигация сервера"** для доступа к основным функциям:
- **Начать играть** — информация о регистрации на игры
- **Служба поддержки** — создание тикета помощи

### Игровой профиль

Команда `/profile` показывает:
- Текущую активность
- Предстоящие игры
- Историю игр
- Статистику проведённых игр
- Количество приглашённых пользователей
- Любимого персонажа
- Полученные лайки
