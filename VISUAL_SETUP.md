## Обзор визуальных элементов

Бот использует следующие визуальные элементы:

Каждый персонаж имеет два изображения:

Каждый персонаж и категория имеют уникальные эмодзи сервера.

## Настройка изображений персонажей

### Требования к изображениям

**Основные изображения (`{uniqueID}.png`):**
- Формат: PNG (с прозрачностью) или JPG
- Рекомендуемый размер: 512x512 px
- Максимальный размер файла: 8 МБ
- Стиль: портрет персонажа

**Профильные изображения (`{uniqueID}_profile.png`):**
- Формат: PNG (с прозрачностью) или JPG
- Рекомендуемый размер: 1200x400 px (широкий баннер)
- Максимальный размер файла: 8 МБ
- Стиль: горизонтальный баннер с персонажем

### Добавление нового персонажа

1. Подготовьте два изображения:
   ```
   assets/characters/mycharacter.png       (512x512)
   assets/characters/mycharacter_profile.png (1200x400)
   ```

2. Добавьте запись в `src/structures/GameCharacters.ts`:
   ```typescript
   new GameCharacter()
       .setName("Имя Персонажа")
       .setTitle("Абсолютный [Титул]")
       .setCategory("thh")           // ID категории
       .setUniqueID("mycharacter")    // Уникальный ID (без пробелов)
       .setEmoji("myemoji:1234567890123456789")  // Эмодзи сервера
       .setRoleID("1234567890123456789")          // ID роли (опционально)
   ```

3. Перезапустите бота для применения изменений.

### Замена существующих изображений

Замените файлы в папке `assets/characters/` на новые с теми же именами файлов.

## Настройка эмодзи сервера

### Список необходимых эмодзи

#### Эмодзи категорий игр
| Название эмодзи | Категория | Использование |
|-----------------|-----------|---------------|
| `thh` | Trigger Happy Havoc | Выбор категории |
| `gd` | Goodbye Despair | Выбор категории |
| `kh` | Killing Harmony | Выбор категории |
| `udg` | Ultra Despair Girls | Выбор категории |
| `pt` | Program Future / Personal Talents | Выбор категории |
| `oc` | Original Characters | Выбор категории |

#### Эмодзи персонажей
Каждому персонажу нужен уникальный эмодзи. Формат названия: `{uniqueID}`

Примеры:
- `sayaka`, `toko`, `kiyotaka`, `makoto`, `kyoko`, etc.

#### Системные эмодзи
| Название | Использование |
|----------|---------------|
| `Praise` | Раздел похвалы в профиле |
| `Like` | Иконка лайков |
| `Profile` | Заголовок профиля |
| `Status` | Текущая активность |
| `Clipboard` | Общая статистика |
| `Latter` | Информация о приглашениях |

### Как добавить эмодзи на сервер

1. Откройте настройки сервера → **Эмодзи**
2. Нажмите **Загрузить эмодзи**
3. Загрузите изображение (PNG, JPG, GIF)
4. Назовите эмодзи согласно таблице выше
5. Повторите для всех необходимых эмодзи

**Рекомендуемый размер эмодзи:** 128x128 px

## Создание ролей для персонажей

### Структура ролей

Для каждой категории создайте роль:

| Роль | Цвет | Назначение |
|------|------|------------|
| Trigger Happy Havoc | #FF6B6B (красный) | Участники этой категории |
| Goodbye Despair | #4ECDC4 (бирюзовый) | Участники этой категории |
| Killing Harmony | #A8E6CF (зелёный) | Участники этой категории |
| Ultra Despair Girls | #C7CEEA (фиолетовый) | Участники этой категории |
| Program Future | #FFD93D (жёлтый) | Участники этой категории |

### Роли отдельных персонажей

Для каждого персонажа можно создать индивидуальную роль:
1. Настройки сервера → **Роли** → **Создать роль**
2. Название: имя персонажа (например, "Макото Наэги")
3. Цвет: уникальный для персонажа
4. Отображать отдельно от остальных: ✅ Да

### Привязка ролей к персонажам

В файле `src/structures/GameCharacters.ts` установите `roleID`:

```typescript
new GameCharacter()
    .setName("Макото Наэги")
    .setUniqueID("makoto")
    .setRoleID("1234567890123456789")  // ID созданной роли
```

Создайте файл `.env` со следующими значениями:

```env

# Канал для приватных заявок на игру

# Категории для каналов управления играми

NAVIGATION_CHANNEL_ID=1234567890123456789

# Канал приветствий
WELCOME_CHANNEL_ID=1234567890123456789

# Роль для уведомлений о новых участниках
WELCOME_ROLE_ID=1234567890123456789
```

## Создание каналов и категорий

### Пошаговая инструкция

#### Шаг 1: Создание категорий

1. Нажмите **+** рядом с названием сервера
2. Выберите **Создать категорию**
3. Назовите категорию (например, "🎮 ИГРЫ")
4. Настройте права доступа

#### Шаг 2: Создание текстовых каналов

1. Нажмите **+** рядом с категорией
2. Выберите **Создать текстовый канал**
3. Введите название (без пробелов, используйте дефисы)
4. Настройте права доступа

#### Шаг 3: Получение ID каналов

1. Включите **Режим разработчика** в настройках Discord
2. Нажмите правой кнопкой на канал
3. Выберите **Копировать ID**

## Настройка embed сообщений

### Цвета embed

Основной цвет бота: **#2F3136** (RGB: 47, 49, 54)

Цвета для разных ситуаций:
| Ситуация | Цвет | HEX |
|----------|------|-----|
| Обычное сообщение | Серый | #2F3136 |
| Успех | Зелёный | #78F937 |
| Предупреждение | Оранжевый | #FFA500 |
| Ошибка | Красный | #FF0000 |
| Информация | Синий | #3498DB |

### Кастомизация embed

Изменения в коде для кастомизации:

```typescript
// Изменение цвета
.setColor([R, G, B])        // RGB формат
.setColor("#HEXCOLOR")       // HEX формат

// Изменение заголовка
.setTitle("Ваш заголовок")

// Изменение описания
.setDescription("Ваш текст")

// Добавление полей
.addFields(
    { name: "Название поля", value: "Значение", inline: true }
)

// Изменение футера
.setFooter({ text: "Текст футера", iconURL: "url_иконки" })

// Изменение изображения
.setImage("attachment://image.png")
.setThumbnail("url_миниатюры")
```

## Кастомизация интерфейса

### Изменение текста кнопок

Найдите соответствующий файл кнопки в `src/buttons/` и измените:

```typescript
new ButtonBuilder()
    .setCustomId("navigation.main")
    .setLabel("Ваш текст кнопки")  // <-- Измените здесь
    .setStyle(ButtonStyle.Primary)
```

В файлах команд `src/commands/`:

```typescript
.setName("command_name")
.setDescription("Ваше описание команды")
```

Файл: `src/events/NavigationInit.ts`

const content = `# Ваш заголовок
