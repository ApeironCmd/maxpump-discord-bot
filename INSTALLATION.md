## Установка на Windows VDS

### Шаг 1: Установка Node.js

1. Откройте браузер на сервере
2. Перейдите на [nodejs.org](https://nodejs.org/)
3. Скачайте LTS версию (Long Term Support)
4. Запустите установщик `node-vXX.XX.X-x64.msi`
5. Следуйте инструкциям установщика
6. После установки откройте командную строку и проверьте:

```cmd
node --version
npm --version
```

Должны отобразиться версии установленных программ.

### Шаг 2: Установка Git

1. Перейдите на [git-scm.com](https://git-scm.com/download/win)
2. Скачайте установщик для Windows
3. Запустите `Git-2.XX.X-64-bit.exe`
4. Выберите настройки по умолчанию
5. Проверьте установку:

```cmd
git --version
```

### Шаг 3: Клонирование проекта

```cmd
cd C:\Users\Administrator\Desktop
git clone <URL_вашего_репозитория> max-pump-bot
cd max-pump-bot
```

Если у вас нет репозитория, скопируйте файлы вручную в папку `C:\max-pump-bot`.

### Шаг 4: Установка зависимостей

```cmd
cd C:\max-pump-bot
npm install
```

Дождитесь завершения установки всех пакетов.

## Настройка бота

### Создание файла .env

Создайте файл `.env` в корне проекта (`C:\max-pump-bot\.env`) со следующим содержимым:

```env
# Токен бота из Discord Developer Portal
TOKEN=your_bot_token_here

# ID канала для приватных заявок на игру
GAME_APPLY_PRIVATE_ID=1234567890123456789

# ID категории для приватных каналов управления играми
GAME_CONTROL_CATEGORY_PRIVATE_ID=1234567890123456789

# ID категории для публичных каналов управления играми
GAME_CONTROL_CATEGORY_OFFICIAL_ID=1234567890123456789
```

### Как получить необходимые ID

1. **ID канала/категории:**
   - В Discord перейдите в Настройки пользователя → Расширенные
   - Включите "Режим разработчика"
   - Нажмите правой кнопкой на канал/категорию → "Копировать ID"

2. **Токен бота:**
   - Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
   - Выберите ваше приложение → Bot → Reset Token
   - Скопируйте токен

### Структура данных

Создайте папку `data` в корне проекта и добавьте файл `servers.json`:

```json
[
    {
        "name": "Сервер #1",
        "ip": "192.168.1.1:27015"
    },
    {
        "name": "Сервер #2",
        "ip": "192.168.1.2:27015"
    }
]
```

## Запуск и автозапуск

### Обычный запуск

```cmd
cd C:\max-pump-bot
npm start
```

### Режим разработки (с автоперезагрузкой)

```cmd
npm run dev
```

### Настройка автозапуска через Планировщик задач

#### Способ 1: Через графический интерфейс

1. Нажмите `Win + R`, введите `taskschd.msc`
2. В правом меню нажмите **Создать задачу**
3. **Вкладка Общие:**
   - Имя: `MAX-PUMP Discord Bot`
   - Описание: `Автозапуск Discord бота MAX-PUMP`
   - ✅ Выполнять для всех пользователей
   - ✅ Выполнять с наивысшими правами
4. **Вкладка Триггеры:**
   - Нажмите **Создать**
   - Начало задачи: `При запуске системы`
   - ✅ Включено
   - Нажмите OK
5. **Вкладка Действия:**
   - Нажмите **Создать**
   - Действие: `Запустить программу`
   - Программа: `cmd.exe`
   - Аргументы: `/c "cd /d C:\max-pump-bot && npm start"`
   - Начать в: `C:\max-pump-bot`
   - Нажмите OK
6. **Вкладка Условия:**
   - ❌ Снимите галочку "Запускать только при питании от сети"
7. **Вкладка Параметры:**
   - ✅ Перезапускать при сбое: каждые 5 минут, до 3 раз
   - Нажмите OK

#### Способ 2: Через командную строку (от администратора)

```cmd
schtasks /create /tn "MAX-PUMP Discord Bot" /tr "cmd /c \"cd /d C:\max-pump-bot && npm start\"" /sc onstart /ru SYSTEM /rl HIGHEST /f
```

### Проверка автозапуска

1. Перезагрузите сервер
2. Откройте Диспетчер задач → Процессы
3. Найдите процесс `node.exe`

## Добавление бота на сервер

### Пошаговая инструкция

#### Шаг 1: Создание приложения

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Войдите через ваш Discord аккаунт
3. Нажмите **New Application**
4. Введите имя: `MAX-PUMP Bot`
5. Нажмите **Create**

#### Шаг 2: Создание бота

1. В левом меню выберите **Bot**
2. Нажмите **Add Bot**
3. Подтвердите действие

#### Шаг 3: Получение токена

1. В разделе **TOKEN** нажмите **Reset Token**
2. Скопируйте токен (он отображается один раз!)
3. Вставьте токен в файл `.env`

#### Шаг 4: Настройка Gateway Intents

В разделе **Privileged Gateway Intents** включите:
- ✅ **SERVER MEMBERS INTENT** — для отслеживания участников сервера
- ✅ **MESSAGE CONTENT INTENT** — для чтения содержимого сообщений

#### Шаг 5: Генерация ссылки приглашения

1. Перейдите в **OAuth2 → URL Generator**
2. **SCOPES:**
   - ✅ `bot`
   - ✅ `applications.commands`
3. **BOT PERMISSIONS:**
   ```
   ✅ View Channels
   ✅ Manage Channels
   ✅ Manage Roles
   ✅ Send Messages
   ✅ Embed Links
   ✅ Attach Files
   ✅ Read Message History
   ✅ Manage Messages
   ✅ Use Slash Commands
   ✅ Use External Emojis
   ✅ Create Public Threads
   ✅ Create Private Threads
   ✅ Send Messages in Threads
   ✅ Manage Threads
   ✅ Mention Everyone
   ✅ Move Members
   ```
4. Скопируйте сгенерированную ссылку

#### Шаг 6: Приглашение бота

1. Вставьте ссылку в браузер
2. Выберите целевой сервер
3. Нажмите **Authorize**
4. Пройдите CAPTCHA если требуется

## Устранение неполадок

### Бот не запускается

**Ошибка: Cannot find module 'discord.js'**
```cmd
cd C:\max-pump-bot
npm install
```

**Ошибка: TOKEN is invalid**
- Проверьте токен в файле `.env`
- Убедитесь, что токен скопирован полностью

**Ошибка: ENOENT: no such file or directory**
- Проверьте существование папки `data`
- Создайте необходимые JSON файлы

### Бот не отвечает на команды

1. **Проверьте подключение к интернету**
2. **Проверьте токен бота**
3. **Убедитесь, что бот добавлен на сервер**
4. **Проверьте права доступа бота:**
   - Бот должен иметь роль с соответствующими разрешениями

### Команды не регистрируются

```cmd
# Перезапустите бота
npm start
```

Подождите до 1 часа для полной регистрации slash-команд.

### Ошибки TypeScript

```cmd
# Переустановите типы
npm install --save-dev @types/node @types/express
```

### Логи бота

Логи находятся в консоли при запуске. Для сохранения логов:

```cmd
npm start > logs.txt 2>&1
```
